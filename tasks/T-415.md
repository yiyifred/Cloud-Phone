## 任务描述
后端容器以 root 运行（Dockerfile 无 `USER`），配合 `network_mode: host` 时任何容器内 RCE 都直接拿到宿主网络与
root 权限下的挂载卷（S-14）。

做法：
1. 创建非特权用户（`cloudphone`，uid 10001），把 `/app`、`/data`（数据目录）chown 给该用户，Dockerfile 末尾 `USER 10001`；
2. 需要 root 的步骤（apt、chmod、pip 安装）保持在 `USER` 之前；
3. 数据目录改为 `ENV CLOUD_PHONE_DATA_DIR=/data` 并 `VOLUME /data`，compose 里挂宿主机目录；
4. compose：保留 `network_mode: host`（ADB/局域网发现确实需要），但补 `read_only: true` 不可能（需要写 /data 与 /tmp），
   改为 `security_opt: [no-new-privileges:true]` 与 `cap_drop: [ALL]` 并显式加回 `NET_ADMIN`（如确需）；
5. 若存在 frontend Dockerfile，同样加非 root + `no-new-privileges`。

## 验收标准
- [ ] Dockerfile 有 `USER` 且非 0
- [ ] 数据目录权限由容器内用户可写（`chown` 已做）
- [ ] compose 有 `no-new-privileges`，`cap_drop` 不留 `ALL` 全量特权（如加回需注释说明原因）
- [ ] 若本机有 docker：`docker build` 通过；无 docker 则在输出中写明「未构建验证」
