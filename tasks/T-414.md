## 任务描述
`AndroidManifest.xml` 里 `android:allowBackup="true"` 与 `android:usesCleartextTraffic="true"` 同时存在：
前者让 `adb backup`/云备份可以导出已保存的后端地址与凭据；后者在**所有**域名放行明文 HTTP，
而项目实际只需要访问局域网内的自建后端（`http://<lan-ip>:3000`）。

做法：
1. `allowBackup` 改 `false`，保留 `dataExtractionRules` 与 `fullBackupContent` 但内容收紧为「全部排除」；
2. `usesCleartextTraffic` 改 `false`，把明文放行下沉到 `network_security_config.xml`：
   `base-config cleartextTrafficPermitted="false"`，另加 `domain-config cleartextTrafficPermitted="true"`
   覆盖私有网段常见写法不可行（domain 只能写域名/IP，不能写网段），因此改为：仅当用户填写的是私有地址时由运行时判断，
   **配置层面默认全禁**，并在 `network_security_config.xml` 里以注释说明「如需调试局域网 http，请在 debug 变体覆盖」；
3. 在 `AndroidManifest.xml` 增加 `android:debuggable` 不加（由构建类型决定），但补 `tools:replace` 冲突时的说明不必要；
4. 同步检查 `CloudPhoneApplication`/网络层是否硬编码了 http，如需要，给 debug 变体加 `usesCleartextTraffic` 覆盖（用 `src/debug/AndroidManifest.xml`）。
