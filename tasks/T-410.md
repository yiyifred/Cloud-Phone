## 任务描述
加上 CSP（T-405）后整页白屏：`#app` 只剩 `<div class="n-config-provider"><!----><!----></div>`，控制台仅一条
`EvalError: Evaluating a string as JavaScript violates the following Content Security Policy directive ... 'unsafe-eval' is not an allowed source of script`。

根因：`vue-i18n` 的 esm-bundler 构建把 `__INTLIFY_JIT_COMPILATION__` 等能力开关留给构建方定义；未定义时走
非 JIT 分支，消息在运行时用 `new Function` 编译，被 `script-src` 拦截 → 挂载失败 → 白屏（不是 T-405 之前就存在的缺陷）。

修复：在 `vite.config.js` 的顶层 `define` 中显式打开 JIT（`__INTLIFY_JIT_COMPILATION__: true`）并把
`__VUE_I18N_LEGACY_API__`（项目用 composition API）、`__VUE_I18N_FULL_INSTALL__`、`__VUE_PROD_DEVTOOLS__`、
`__INTLIFY_PROD_DEVTOOLS__`、`__INTLIFY_DROP_MESSAGE_COMPILER__`、`__VUE_PROD_HYDRATION_MISMATCH_DETAILS__` 一起定死。
JIT 分支改用 AST 直接组装渲染函数（`format(ast)`），全程不 eval，因此不需要在 CSP 里开 `'unsafe-eval'`。

注意：`define` 必须写在 vite 配置顶层，且值用布尔而非字符串（字符串 `"false"` 是真值，会让开关反向生效）。
