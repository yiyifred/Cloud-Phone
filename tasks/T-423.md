## 任务描述
T-422 里画廊角标是「逐台探测」：设备列表有 N 台就发 N 个加密请求，每 20 秒一轮。
设备一多就是轮询风暴，而租约本身就是「少数设备被占用」的状态，没必要按设备问。

后端新增 `GET /api/devices/control`：一次返回所有被占用设备的快照（`items[].serial + held/mine/holder/expiresAt`）
与 `enforced`；未出现在 items 里的设备即空闲。`mine` 按请求者会话计算。

前端 `refreshSerials` 改为优先走列表接口，并把「列表里没有的设备」清成空闲（否则角标会一直停在「控制中」）；
列表接口不可用时退回逐台串行探测，保证老后端/异常情况下角标不整页空白。

## 验收标准
- [x] `GET /api/devices/control` 返回全部租约，`mine` 按请求者会话区分
- [x] 前端一次请求覆盖整页设备；缺失即空闲
- [x] 列表失败时仍能逐台探测（有 warn 日志，不静默）
- [x] `node --check` 与 `vite build` 通过
