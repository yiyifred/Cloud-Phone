## 任务描述
`index.html` 通过 `fonts.googleapis.com` 外链加载 DM Sans / Space Grotesk。内网/离线环境会静默回退，
首屏还会多一次跨域 DNS + TLS；CSP 也因此被迫放行两个外部源。

改为**自托管/系统字体栈**：
1. 删除两个 `preconnect` 与 `fonts.googleapis.com/css2` 链接；
2. `main.css` 里 `--font-body` / `--font-heading` 改成系统栈（中文优先 PingFang SC / Microsoft YaHei / Noto Sans CJK SC，
   西文 -apple-system / Segoe UI Variable / Inter / system-ui），标题与正文的层级靠字重与字号区分；
3. 收窄 `server.mjs` 的 CSP：`style-src` 去掉 `https://fonts.googleapis.com`，`font-src` 去掉 `https://fonts.gstatic.com`；
4. 确认没有其它 CSS 引用 `DM Sans`/`Space Grotesk` 字面名。

## 验收标准
