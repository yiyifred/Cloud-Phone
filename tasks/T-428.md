## 任务描述
「H.265 假支持」：设置里能选 H.265/AV1 编码器，但网页播放器只解析 H.264 Annex-B
并只用 `avc1.*` 构造 `VideoDecoder` 配置（`utils/h264-config.js:24`、
`utils/ws-scrcpy-annexb-player.js:181`），选中即黑屏。

修复：
1. 新增 `utils/webcodecs-support.js`：`VideoDecoder.isConfigSupported` 探测
   avc1.42E01E / hvc1.1.6.L93.B0 / av01.0.05M.08，缓存结果；
   同时声明 `PLAYER_DECODABLE_CODECS = {h264}`——浏览器能解不等于本项目播放器能解。
2. `utils/mirror-encoder-utils.js` 新增 `markUnsupportedEncoderOptions` /
   `firstSelectableEncoderOption`：给不可用条目置 `disabled` + 说明后缀
   （「（网页端仅支持 H.264）」/「（浏览器无法解码）」）。
3. 新增 `composables/useVideoEncoderOptions.js`：封装「探测 + 标记 + 已选回退」，
   回退时回调调用方提示；设备只有不可解码的编码器时也给出警告。
4. 接入 `MirrorCastVideoSection.vue`（下拉与帮助文案）、`MirrorCastSettings.vue`、
   `CameraCastSettings.vue`（都是同一个编码器选择器）。
