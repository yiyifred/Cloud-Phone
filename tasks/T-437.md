## 任务描述
1) 修复 1.28.0 引入的 Android 编译失败：`ServerUrl` 在子包中被引用但未 import。
2) 用 Waydroid 作为被控设备，验证「后端 → scrcpy-server → WebSocket 视频流」在明文与 TLS 两种形态下都能出画面。

## 上下文
- `ServerUrl` 位于 `com.yiyi.cloud_phone`，`cast/`、`terminal/` 是子包，必须显式 import。
- 投屏协议：客户端连 `/api/devices/<serial>/cast/ws`，服务端先发 `scrcpy_initial`，**必须再发 type-101 视频参数包**，否则 `WsCastSession.join()` 停在 "waiting for stream parameters" 不出帧（`backend/source/scrcpy/server/src/main/java/com/genymobile/scrcpy/ws/WsCastSession.java`）。

## 复跑步骤
1. Waydroid：`pipewire` + `pipewire-pulse`（`XDG_RUNTIME_DIR=/tmp/xdg`）→ `weston --backend=headless-backend.so --socket=wayland-0` → `dbus-run-session -- waydroid session start`
2. 授权 adb：容器内写 `/data/misc/adb/adb_keys`（system:shell 640），`setprop service.adb.tcp.port 5555; stop adbd; start adbd`，宿主 `adb connect 192.168.240.112:5555`
3. 防冻结：`echo 0 > /sys/fs/cgroup/lxc.payload.waydroid/cgroup.freeze`，或常驻 thaw 循环
4. 构建 scrcpy-server：`JAVA_HOME=<zulu-21>` + `ANDROID_SDK_ROOT=/opt/android-sdk` 后 `node tools/build-scrcpy-server.mjs`（gradle 需 9.3.1，官方下载可能 504，可用腾讯镜像）
5. 后端：`CLOUD_PHONE_DATA_DIR=/tmp/wd-backend BACKEND_PORT=3999 node src/index.js`（TLS 加 `BACKEND_TLS=1`）
6. 客户端脚本见对话中的 cast-probe：登录（AES-GCM 信封）→ `cast/start` → WS 发 type-101 → 收帧
