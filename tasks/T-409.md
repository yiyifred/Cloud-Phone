## 任务描述
`@media (max-width: 900px)` 把侧栏改成横排后，`.console-layout` 仍是「单列 + 自动行高」，CSS Grid 的 `align-content: stretch` 会把侧栏这一行一起拉高：768×1024 下实测侧栏占 425px、正文被挤到屏幕下半截。另外横排后按钮空间不足，`退出登录` 被按字折行成竖排。

修复：
1. `≤900px` 时显式写 `grid-template-rows: auto minmax(0, 1fr)` 与 `align-content: start`；
2. 侧栏横排时收紧 `gap`/`padding`，加 `overflow-x: auto` 并隐藏滚动条；
3. `.sidebar__tab`/`.sidebar__logout` 加 `white-space: nowrap`。

## 验收标准
- [x] 768×1024 侧栏高度 425px → 140px，正文紧接其下
- [x] 900×800 侧栏 78px，无横向溢出
- [x] 退出登录按钮 81×38（竖排）→ 112×38（横排）
- [x] 1440 / 900 / 768 / 390 四档 `scrollWidth === innerWidth`

实测数据来自 ego 浏览器 CDP 截图与 `getBoundingClientRect`：`aside.sidebar 0,0 768x425`、`main.main-panel 0,425 768x644`（改前）；改后 `sbH=140`。
