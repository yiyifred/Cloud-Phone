## 任务描述
三处危险操作仍用 `window.confirm`：断开设备、抢占控制权、吊销分享链接。
原生框无法标危险态、语言/样式不受控、会阻塞渲染线程，也不利于可访问性。

做法：
1. `utils/confirm-dialog.js`：reactive 状态 + `requestConfirm()` 返回 Promise<boolean>，
   同一时刻只允许一个待决框（旧的按取消结算，避免 Promise 悬挂）。
2. `components/ui/ConfirmDialog.vue`：naive-ui NModal，`danger` 时确认按钮为 error 色，
   默认焦点在「取消」，移动端按钮 ≥44px。
3. `AppShell.vue` 全局挂载一次；三处调用改为 `await requestConfirm({ message, confirmText, danger: true })`。
4. 五语 `common.confirmTitle / confirm / cancel`。
