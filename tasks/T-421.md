## 任务描述
把 T-420 的租约接到「真正会互相打架」的入口上。要求**默认不破坏单用户流程**：
`isControlEnforced()` 为 false（advisory）时只记日志/透传，为 true 时才拒绝。

接入点（按优先级）：
1. **投屏控制消息**：`routes/device-cast-ws.js` 里来自浏览器的控制帧（touch/key/clipboard）在 strict 模式下
   校验 `assertControlPermission(serial, sessionToken)`，不持有则丢弃并回一条 `{"type":"control-denied", holder}`
   文本帧，不要把设备搞崩。
2. **ADB 终端 WS**：strict 模式下非持有者不得开 shell（回 403 或关闭码 4403 + 原因）。
3. **写类 HTTP 路由**：`device-apps-routes`（install/uninstall/force-stop/disable）、
   `device-files-routes`（上传）在 strict 模式下校验；403/409 用现有 sendProtectedJson 格式。

注意：
- WS 握手阶段已能拿到请求里的 cookie（`verifyWebSocketSession`），需要把 sessionToken 传进 handle* 函数；
- 错误必须是可读中文 + 结构化 `error` 字段，禁止静默；
- 单文件仍要 ≤300 行，超额就抽 helper 到 `services/control-guard.js`。

## 验收标准
- [ ] advisory 模式（默认）下所有既有流程行为不变（curl/WS 冒烟通过）
- [ ] strict 模式下非持有者的控制帧被拒且收到 `control-denied`
- [ ] strict 模式下非持有者上传/安装返回 409（带 holder）
- [ ] strict 模式下持有者全部操作正常
- [ ] `node --check` 通过
