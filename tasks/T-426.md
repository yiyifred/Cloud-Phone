## 任务描述
现有认证只有「一个密码 = 全部权限」：想让同事看一眼设备画面就得把管理密码交出去，顺带把安装、卸载、
终端权限全给了。引入第二种凭据：**只读分享链接**。

- `services/share-tokens.js`：内存态分享令牌，只存 `sha256(token)`；TTL 默认 24 小时、上限 30 天；
  记录 label / createdAt / expiresAt / lastUsedAt；支持吊销；明文令牌只在创建时返回一次。
- `routes/share-routes.js`：`POST /api/share`、`GET /api/share`、`DELETE /api/share/:id`（均需管理员会话）。
- `app.js`：鉴权闸门在没有管理员会话时回落到 `cloud_phone_share` cookie；
  viewer 只允许 `GET/HEAD`，且排除 `/api/share*` 与 `/api/auth*`（否则「看一眼」的凭据能给自己续期或改密码）；
  新增 `GET /api/access`（返回 role/readOnly）与 `GET /api/share/redeem?token=`（302 种 cookie 后跳回控制台）。
- `config/auth.js` 增加 `SHARE_COOKIE_NAME`；`isPublicApiPath` 放行 redeem（凭据在 query 里，必须先于闸门执行）。

## 验收标准
- [x] redeem：合法 token 302 到 `/?share=1` 且 Set-Cookie 带 HttpOnly + SameSite=Lax + Max-Age；非法 token 302 到 `/?share=invalid`
- [x] viewer 访问 `GET /api/access` 得到 `{role:"viewer", readOnly:true}`
- [x] viewer 的写请求 403 `viewer_forbidden`；访问 `/api/share` 也 403
- [x] 吊销后同一 cookie 立即 401
- [x] 无凭据 401；管理员会话行为不变
- [x] `node --check` 通过
